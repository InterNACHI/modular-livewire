### Added

- Livewire plugin for `internachi/modular` v3 plugin architecture
- Automatic discovery of Livewire components from module `src/Livewire/` directories
- Component registration with `{module}::{kebab-name}` naming convention
- Support for nested components with dot notation
- Service provider with automatic plugin registration
